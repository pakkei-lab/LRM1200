# LRM1200 V2.5

- The POI API request includes only checked categories.
- Hotel and restaurant are unchecked by default.
- The loading circle no longer shows the zoom number.
- The POI button is disabled and grey below Zoom 12.
- It is also disabled if no POI category is selected.
- Manual POI loading, category priority, display limits, address copying, and GPS address fallback are retained.
